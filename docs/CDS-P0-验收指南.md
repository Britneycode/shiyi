# CDS P0 视觉验收指南

> 配套：验收页 `.preview/audit-p0.html`（本地预览服务 `http://127.0.0.1:8899/.preview/audit-p0.html`，视口 ≥1120px 才出三栏）。
> 验收环境已注入假数据：3 个助手、3 件事、3 条知、5 种消息类型（user / assistant / proactive / system / handoff）。
> 本指南只验 P0 已落地的项。**视觉信号本就细微**——验收的重点是"没有翻车"，不是"看出强烈差异"。

---

## 0. 打开验收页

```bash
# 项目根（需先装 python）
python -m http.server 8899 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8899/.preview/audit-p0.html`。顶部工具条有「浅色 / 深色 midnight / 开关抽屉 / 开关模态 / Toast」五个按钮。

## 1. P0 落地项 ⇄ 在验收页哪里看

| P0 项 | 在验收页看哪里 | 你应该看到什么 |
|---|---|---|
| **表面阶梯 surface 0–3** | 整个三栏布局 | 左/右栏略深、中栏略浅、卡片/气泡再浅一档；层级靠底色微差，不靠边框分隔 |
| **alpha 边框（--border 桥接）** | 三栏分隔线、助手卡边、输入框边、气泡边 | 边框淡、中性灰（不带暖褐色调）；三栏之间没有"框"感 |
| **阴影五档 + popover 双环** | 点「开关抽屉」「开关模态」「Toast」 | 浮层有分层阴影：紧贴的 1px 外环 + 弥散底影，不是一整坨灰 |
| **composer 三态阴影** | 底部输入框 | 常态轻阴影；鼠标悬停时阴影略深；点击聚焦时再加一圈同色描边 |
| **发丝补偿（0.5px @2dppx）** | 任意 1px 边框（在 2x/3x 屏） | 边框在高分屏仍是细线，不会糊成 1px 灰条 |
| **动效令牌 + .sy-squish** | （P2 才挂到按钮，P0 仅备令牌） | — |
| **排版修正 --font-ui 系统栈** | 全文 | 中文用系统中文字体（PingFang / 雅黑），不再强行拉 Inter |
| **深色字重逆补偿** | 切「深色 midnight」看标题 | 深色下标题字重从 600 压到 565，字不会显得发胀/光渗 |
| **svg.i 光学对齐** | 助手卡、按钮里的 16px 图标 | 图标与同行中文基线对齐，不下沉不飘 |
| **IME 守卫** | 底部输入框，中文输入法打字选词按 Enter | 候选窗按 Enter 是**上屏**，不会发送；上屏后再按 Enter 才发送 |

## 2. 逐项验收操作

### 2.1 表面阶梯 + alpha 边框（最容易看出）

1. 默认浅色，看左栏 / 中栏 / 右栏的**底色过渡**：左栏底比页面略深，右栏"事/知"卡又比栏底浅一点。层级靠 4 档米白色微差建立。
2. 把视口缩小再放大（拖窗口边框），看三栏的分隔线：是 1px 极淡的中性灰线，不是暖褐色也不发蓝。

✗ 不合格信号：三栏分隔线颜色突兀 / 一眼看出是暖褐或粉色。

### 2.2 阴影五档 + popover 双环

1. 点顶部「开关抽屉」→ 右侧滑出详情抽屉。
   - 浅色：抽屉边缘应有 `1px` 极淡外环 + 柔和的弥散底影，**不是一大团灰**。
   - 点「深色 midnight」再看：抽屉边缘多了一圈**白色内高光**（`inset 0 0 0 1px rgba(255,255,255,.10)`），深色浮层的通透感来源。
2. 点「开关模态」→ 设置弹窗居中，同样能看到双环阴影。
3. 点「Toast」→ 右下角小提示，阴影比抽屉更轻。

✗ 不合格信号：浮层像"贴纸一样贴在背景上"（阴影缺失）；或阴影是一坨大灰块（没分档）。

### 2.3 composer 三态阴影（验收重点）

1. 滚到中栏底部输入框。
2. 常态：输入框有轻阴影 + 1px 淡描边。
3. 鼠标悬停：阴影加深一点，描边稍浓。
4. 点击输入框聚焦：阴影最深，描边最浓，可能带第二圈同色描边。
5. 切深色再验一遍：三态差异仍可见，且描边是白色内高光而不是深色描边。

### 2.4 深色字重逆补偿

1. 切「深色 midnight」。
2. 看左栏"拾遗 / Hana"、助手名、聊天标题、事卡标题——这些 600 字重的标题在深色下应该**没有发胀**。
3. 对照：打开 DevTools，临时删 `panel.css` 里 `html[data-tone="dark"] .btn,.wordmark,...` 那段逆补偿规则，标题立刻变胖——恢复后变回瘦。

✗ 不合格信号：深色下标题字明显比浅色下胖/糊。

### 2.5 IME 守卫（功能性，最关键）

1. 点中栏底部输入框。
2. 切到中文输入法（微软拼音/搜狗等）。
3. 输入 `nihao` 候选窗出来后**按 Enter**——此时应该是"选词上屏"，输入框里出现「你好」，**不发送**。
4. 再按一次 Enter——发送。

✗ 不合格信号：候选窗按 Enter 直接把 `nihao` 或半成品拼音发了出去。

### 2.6 图标对齐

1. 看左栏助手卡右侧的小箭头、设置按钮里的齿轮、聊天头部"事/知面板"按钮里的图标。
2. 这些 16px svg 与同行文字基线应**居中对齐**，不应下沉 1–2px。

## 3. 常见"看似翻车实为预期"

- **三栏分界变淡** → 预期。CDS 的克制感就来自"边框更淡更中性"。原先暖褐 `rgba(122,96,88,.18)` 在米色底上是"框"，现在中性 `rgba(59,61,63,.10)` 是"分界"。
- **右栏底色和页面融在一起** → 预期。表面阶梯的微差本来就是为了消除"卡片感"。验收截图右下看似空白，实际右栏内容完整。
- **浅色下没有"惊艳感"** → 预期。P0 只做结构骨架，不动品牌色；视觉亮点是 P1（滚动渐隐）和 P2（按压微缩放）的事。
